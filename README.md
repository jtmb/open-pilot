# OpenPilot for VS Code

This project is an unattended AI app builder using VS Code Copilot, with a Next.js-based, Docker-native approach, authentication, and a web UI similar to ChatGPT. The app allows users to input requirements, select a Copilot LLM model (defaulting to free models), and watch as the AI builds the app end-to-end.

## Features
- Next.js (TypeScript, app directory)
- Tailwind CSS
- NextAuth.js authentication
- Docker & Docker Compose
- code-server (browser-based VS Code)
- Copilot API integration (planned)
- Chat UI, sidebar for jobs, dashboard
- Documentation generation
